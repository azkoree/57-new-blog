WSQ_PictureStage

一个基于 GF 体系的「图片演出」插件。可以在游戏中显示 img/pictures 图片或 system/IconSet 图标，并套用与 GF 精灵核心完全一致的移动动画（40+ 种缓动曲线）播放入场/退场/移动演出。

支持事件相对显示、原点设置、演出预设、移动演出元素等功能。

功能介绍

显示图片演出

显示一张 img/pictures 下的图片，并播放入场演出。

  • 图片：从 img/pictures 文件夹中直接选择
  • 图片ID：用于管理/移动/清除的编号，同一 ID 再次显示会覆盖旧图
  • 最终位置 X/Y：图片最终到达的屏幕坐标
  • 原点：中间 = X/Y 指图片中心；左上 = X/Y 指图片左上角
  • 预设名称：填写插件参数「演出预设」中配置好的预设名；留空使用默认演出参数

显示图标演出

显示一个 system/IconSet 图标，并播放入场演出（绝对坐标）。

  • 图标编号：system/IconSet 中的图标编号
  • 演出ID：用于管理/移动/清除的编号，同一 ID 再次显示会覆盖旧图
  • 最终位置 X/Y：图标中心最终到达的屏幕坐标
  • 原点：中间 / 左上
  • 预设名称：同「显示图片演出」

清除图片演出

按 ID 清除某张演出图片/图标，或填 0 清除全部。

  • 淡出退场（默认）：用 GF 原生 invertInitParamData() 倒放位置/透明度弹道，图片沿与入场相同的曲线飞回起点，缩放/旋转同步反向，形成真正的“移动退场”
  • 立即清除：瞬间移除

显示事件相对演出

以某个事件为基准点，在其上/下/左/右显示图片或图标，并可追加 XY 偏移。

  • 素材类型：图片 / 图标
  • 目标事件：本事件 / 指定 ID 的事件 / 玩家 / 变量指定 ID 的事件
  • 相对位置：上方 / 下方 / 左方 / 右方
    • 上方 = 事件脚底中心上移 1 格
    • 下方 = 下移 1 格
    • 左/右 = 左右平移 1 格并垂直居中
    • 可再通过偏移X/Y微调
  • 原点：中间 = 图片/图标中心对齐事件相对点；左上 = 左上角对齐事件相对点
  • 预设名称：同上

移动演出元素

按演出 ID 移动已有的图片/图标，使用 GF 移动动画。

  • 目标类型：
    • 事件相对位置：可指定本事件/指定 ID 事件/玩家/变量指定 ID 事件，以及上/下/左/右和偏移
    • 绝对坐标：可指定目标 X/Y，原点支持左上/中间
  • 移动动画：与 GF_1_CoreOfSpriteUI 完全一致的 MoveAnimation 结构体，包含移动类型（匀速/增减/弹性/InOut 系列等 40+ 种）、时长、延迟、透明度锁定、起点坐标类型（相对/绝对）等
  • 自动补移动：如果显示后立刻移动而素材仍在加载，插件会先登记移动，待加载完成后自动补执行

原点设置

显示图片演出 / 显示图标演出 / 显示事件相对演出均支持原点设置：

  • 中间（默认）：X/Y 指图片/图标中心，与旧版行为一致
  • 左上：X/Y 指图片/图标左上角

演出预设

插件参数「演出预设」可以集中配置入场演出的最终/起始扩大率、角度、不透明度、移动动画等参数，显示类命令只需要填「预设名称」即可引用，命令更简洁。

每个预设包含：

  • 预设名称
  • 最终角度（度）
  • 最终扩大率 X/Y（%，100 = 原始大小）
  • 起始扩大率 X/Y（%，默认 0 = 从极小放大进入）
  • 最终不透明度（0-255）
  • 起始角度（度，可与最终角度不同形成旋转扫入）
  • 移动动画（与 GF_1_CoreOfSpriteUI 相同的 MoveAnimation 结构体）

配合起始/最终扩大率或角度，可以做出“原地微放大”“旋转扫入”等效果，而不只是从无到有弹出。

事件大小

插件参数「事件大小」（默认 48）用于事件相对位置中“1 格”的像素计算。

如果角色行走图较大（如占 2×3 格），把该值改成角色实际占格对应的像素（如 96/144），即可省去逐条命令手动调偏移的麻烦。

脚本接口

以上显示类脚本接口同样支持 paramObj.PresetName = "预设名"；若对象里已直接给出 TargetScaleX 等演出参数，则不会覆盖为预设值。
